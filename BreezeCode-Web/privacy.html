Privacy Policy

Last updated: October 22, 2026

Breeze Code is a desktop app that runs on your computer. There is no Breeze Code account server and no Breeze Code cloud: your code, settings and sign-in details stay on your machine. This page explains what the app and this website do with your information, and which outside services are involved.

Your code and files

Breeze Code opens, edits and runs files directly on your computer. We never receive, upload or store your projects. Checkpoints are saved with Git in your own project folder.

Signing in

Signing in is optional. If you choose Continue with GitHub or Continue with Google, the app talks directly to GitHub or Google to sign you in. It receives your name, username or email address and profile picture, and shows them in the app.

The sign-in token is encrypted with Windows' built-in protection (the same keychain the app uses for API keys) and saved on your computer. Signing out deletes it. We don't receive any of this information.

AI agents and API keys

Agents only run when you ask them to.

  • Local models (Ollama, LM Studio or another server on your computer): your prompts and code stay on your machine.
  • Cloud agents (Claude Code CLI, Codex, Antigravity or an online OpenAI-compatible server): the agent sends your prompt and the parts of your project it needs for the task to its provider. What happens to that data is covered by the provider's own privacy policy and terms.
  • API keys you add are encrypted with Windows' built-in protection and stored only on your computer.

Optional features

  • Discord presence is off until you turn it on. When it's on, the app tells the Discord app on your computer that you're coding in Breeze Code. With extra detail turned on, it can also show the open file and project name.
  • Vibe Mode shows Instagram or Facebook Reels in a separate browser session inside the app. If you sign in to those sites, their cookies are kept on your computer, and your use of them is covered by Meta's own policies.

Updates

The app checks the GitHub releases page for new versions and downloads an update only when you agree. GitHub sees a standard request from your computer, like any download.

This website

  • We use Vercel Web Analytics and Speed Insights to count page visits and measure loading speed. They don't use cookies and report only combined numbers, not who you are.
  • Fonts load from Google Fonts, and the download section asks GitHub for the latest version number. Both services see your IP address when your browser loads them.
  • The live demo on the home page runs entirely in your browser. Nothing you type in it is sent anywhere.

What we don't do

We don't sell your data, show ads, or collect telemetry or crash reports from the app.

Children

Breeze Code isn't directed at children under 13, and we don't knowingly collect information from them.

Changes and contact

If this policy changes, we'll update this page and the date at the top. Questions? Open an issue on GitHub.
